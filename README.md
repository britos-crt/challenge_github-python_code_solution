# Soluções de algoritmos em Python

Esse repositório foi desenvolvido como parte do desafio da formação GitHub Certification da DIO. Ele reúne exemplos introdutórios de programação em Python, com foco em entrada e saída de dados, operações aritméticas e manipulação de strings.

## Objetivo do projeto

Este projeto teve como objetivo utilizar o **GitHub Copilot** e o **GitHub Codespaces** como ferramentas de apoio à solução de algoritmos em Python. A experiência explora como a inteligência artificial pode acelerar o desenvolvimento, sugerir códigos eficientes e contribuir para a produtividade durante o processo de programação.

O Copilot pode auxiliar na elaboração e compreensão de trechos de código, enquanto o Codespaces oferece um ambiente de desenvolvimento acessível pelo navegador, pronto para editar e executar os exemplos. As sugestões geradas devem ser revisadas e testadas para garantir que atendam ao comportamento esperado.

## Módulos

### `calculator.py`

Apresenta uma interação simples pelo terminal: solicita o nome da pessoa, exibe uma saudação personalizada e pede dois valores numéricos e uma operação. O programa calcula soma, subtração, multiplicação ou divisão, e trata a divisão por zero e operações não reconhecidas com mensagens de erro.

### `string_manipulation.py`

Solicita um texto e demonstra métodos nativos de strings do Python: `upper()` para letras maiúsculas, `lower()` para minúsculas, `capitalize()` para capitalizar o início do texto e `title()` para capitalizar cada palavra. Também imprime o texto formatado repetidamente.

## Como executar

É necessário ter Python 3 instalado. No terminal, acesse a pasta do projeto e execute o módulo desejado:

```bash
python calculator.py
```

```bash
python string_manipulation.py
```

No GitHub Codespaces, os mesmos comandos podem ser executados no terminal integrado.
